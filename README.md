# CV Checker Backend

## Description
CV Checker Backend is a service that provides API endpoints for analyzing and processing resumes/CVs. It helps evaluate resumes against job requirements and provides feedback for improvement.

## Features
- Resume parsing and analysis
- Job requirements matching
- Feedback generation
- API endpoints for CV processing

## API Documentation
- POST [localhost:8080/api/matchCV](http://localhost:8080/api/matchCV) - Upload and analyze CV
